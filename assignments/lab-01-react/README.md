## Послідовність виконання

1. Оберіть або погодьте предметну область і сценарії.
2. Створіть **власний** React-проєкт і репозиторій, оформіть README із точними командами.
3. Побудуйте компоненти й керовані форми, перевірте маршрутизацію.
4. Реалізуйте один завершений сценарій роботи з даними через HTTP API.
5. Обробіть loading/empty/error та перевірте некоректне введення й повторне надсилання.
6. Підготуйте демонстрацію та коротке пояснення архітектурних рішень.

Примітка: приклади цього репозиторію слугують **навчальним матеріалом**, а не готовим виконанням індивідуальної ЛР.

Докладні [методичні вказівки](METHODICAL_GUIDE.md) містять приклади коду, команди запуску та перевірку результатів.
