## Послідовність виконання

1. Зафіксуйте очікувані результати трьох користувацьких сценаріїв.
2. Створіть компонентні тести через спостережувану поведінку.
3. Перевірте асинхронні стани, помилку, валідацію та відсутність небажаного виклику.
4. Додайте E2E-перевірку одного завершеного сценарію.
5. Навмисно відтворіть або локалізуйте дефект, збережіть діагностичні докази.
6. Виправте дефект мінімальною зміною та запустіть регресійні тести.

Власні тести й README мають запускатися в репозиторії студента. Звіти лише зі скриншотами без вихідного коду не замінюють відтворюваної перевірки.

Докладні [методичні вказівки](METHODICAL_GUIDE.md) містять приклади коду, команди запуску та перевірку результатів.
