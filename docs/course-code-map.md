## Принципи

- Використовуйте прямі посилання на відповідні README у Moodle – не додавайте копії ZIP для кожної лекції.
- Л1 – мінімальний Python HTTP API та браузерний JavaScript (немає потреби в Node.js).
- Л2 – компонентна декомпозиція на JavaScript до вивчення React.
- Л3–Л15 – наявні приклади; інструменти та команди запуску описано в кожній папці.
- Результати на Expo Web не є підтвердженням поведінки native Android/iOS. Вказуйте перевірений runtime.
- Головна актуальна версія коду – гілка `main`; Moodle посилається на неї.
