# Лекція 1. UI як частина програмної системи

Стартовий TaskApp із `render()`, `uiState`, `tasks` та `addTask()`. Включає невеликий Python HTTP API, тому студент бачить справжні GET/POST запити в Browser DevTools.

## Запуск

З кореня репозиторію:

```bash
python3 examples/lecture-01-ui-system/server.py
```

На Windows: `py -3 examples/lecture-01-ui-system/server.py`. Відкрийте **http://localhost:8000**. Не відкривайте `index.html` як `file://`: тоді запити `/api/tasks` не працюватимуть.

## Ключові файли

- `app.js` – стан UI, рендеринг, події та HTTP запити;
- `index.html` – форма й DOM елементи;
- `styles.css` – мінімальне оформлення;
- `server.py` – локальний HTTP API з даними в оперативній пам'яті.

## Вправи з кодом

1. **Перевірка назви:** змініть `addTask(title)`, перевірте довжину після `trim()` перед викликом `fetch()`.
2. **Empty state:** змініть `render()`; кнопка «Очистити список локально» допоможе перевірити `tasks.length === 0`.
3. **Loading:** у `render()` змінюйте `addButton.disabled` та його текст залежно від `uiState.loading`. Сервер навмисно затримує POST на 0,6 с.
4. **Поле `priority`:** розширте форму, JSON запиту та відображення завдання. Сервер приймає `priority`, якщо клієнт його передав.

Відповідні покращення не реалізовано в стартовому коді. Це завдання студента.

## Перевірка API

- Звичайний POST → HTTP 201.
- Назва `__error__` → імітована помилка HTTP 503.
- Порожня назва → HTTP 400 (клієнтську перевірку додає студент).
- Після перезапуску сервера знову доступні три початкові завдання.
