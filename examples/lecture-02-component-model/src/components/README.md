# Межі компонентів (завдання до лекції 2)

Створіть у цій папці компоненти `TaskForm`, `TaskList`, `TaskItem`. Це стартова структура, а не готові відповіді.

Пропоновані контракти, які треба обґрунтувати самостійно:

- `TaskForm` отримує поточний текст і функцію зворотного виклику для додавання;
- `TaskList` отримує відфільтровані завдання і функцію зворотного виклику для зміни стану;
- `TaskItem` отримує один `task` та викликає `onToggle(task.id)`, не змінюючи список безпосередньо.

Порівняйте цю декомпозицію з React-компонентами в [лекції 3](../../../lecture-03-react-basics/README.md). Сам код лекції 2 використовує стандартні DOM API й не потребує React.
