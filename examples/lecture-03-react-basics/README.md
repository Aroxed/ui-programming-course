# Lecture 3 — React basics

Run `npm run lecture:03` from the repository root. The example demonstrates JSX, function components, props, composition, `map`, and stable `key` values without introducing state.

## Check it in React Developer Tools

Install the React Developer Tools browser extension, open the app, press `F12`, and switch to **Components**.

1. Find `App`, `TaskList`, and `TaskItem` in the component tree.
2. Select a `TaskItem` and inspect its props.
3. Compare the React component tree with the rendered DOM in the **Elements** panel.

Official guide: https://react.dev/learn/react-developer-tools
