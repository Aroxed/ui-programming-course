# Lecture 7 — React Native basics

Run `npm run lecture:07`. The Expo example uses `View`, `Text`, `TextInput`, `Pressable`, `FlatList`, and `StyleSheet`. Open it in a browser, Android emulator, or Expo Go where compatible.

## Check it in React Native DevTools

For a native Expo/React Native run, open the Developer Menu and choose **Open DevTools**, or press `J` in the terminal running Expo.

1. Open **Components** and select the component that renders one task.
2. Compare React Native components (`View`, `Text`, `Pressable`) with the React component tree.
3. Use the element inspector to select an element on the device/emulator.
4. Open **Console** and verify that it is connected to the running app.

For the web preview you may still use ordinary Browser DevTools, but the course treats React Native DevTools as the main debugger for native runs.

React Native DevTools: https://reactnative.dev/docs/react-native-devtools

Expo debugging tools: https://docs.expo.dev/debugging/tools/
